# 轮台绿电制氢项目定容测算

## 储+氢分支

本分支测算不配置光伏、不含炼化用电负荷的储能制氢项目。
`模型/lp_multi.py` 中 `pv_max=0.0`、`green=0.0`、`refinery=0.0`，其他模型参数暂沿用原项目。
光伏单位造价保留 2600 元/kWp：容量上限为零已强制禁配，无需设置无穷大。

年用氢量固定为 3 万吨（`annual_h2_kg=30000000`），各年分别满足。
无检修年按 8760 小时均摊；第 3、6、9 年检修期取氢为零，按其余 8040 小时均摊。

本分支所有优化结果、割平面、调度与典型工况缓存统一放在 `优化缓存/储+氢/分时电价_2026_年用氢3万吨_无绿电约束_v2/`。
`green=0` 时不创建年度绿电占比约束和绿电缺口松弛变量，绿电占比统计不适用。
物理储能口径对所有小时（含首小时）限制电量不超过容量；旧框架校核口径保留。
旧版本割平面不可复用；旧容量仅可用于新一轮初始候选点，必须重新求解各年。
原项目缓存保留在 `优化缓存/` 根目录，不会被自动读取。
显式设置 `CUTS` 或 `DISPATCH_FILE` 时也仅允许使用本分支缓存目录内的文件。

当前购电输入为 `处理后输入/储+氢_分时电价_2026.csv`，运行 `python mk_price.py --tou` 可重建。
2026 年 8760 个小时，时刻代表一小时区间起点，全年各月采用同一划分：
谷段 11:00—18:00 为 0.11 元/kWh；峰段 08:00—10:00、19:00—24:00 为 0.45 元/kWh；
其余平段为 0.28 元/kWh。电量价格直接使用，不叠加原节点杂费；需量费参数暂不改变。
峰价代表储能放电替代内部负荷购电的价格，不设置上网售电收入，也未新增充放电时段硬约束。

注意：`run_all.py` 中的推荐容量 `XREC`、敏感性算例需量下限 `CGMIN` 和报告文字仍沿用原项目，
尚不适合作为新项目完整报告流程。当前可先运行 `python bd10y.py 10 3,6,9` 做定容，
再运行 `python dispatch_10y.py` 按新项目最优容量复算调度。
`lp_multi.py check` 仍会切换为原框架校核参数，不代表本项目参数。

## 目录

| 目录 | 内容 |
|---|---|
| 原始数据 | 项目资料；`renewables.ninja/` 为站址（北纬41.7766°，东经84.2504°）2014—2023年逐时光伏、风电出力（MERRA-2），由 `模型/fetch_ninja.py` 下载 |
| 处理后输入 | 若羌节点逐时电价、逐时光伏出力系数，由原始数据生成；`_若羌节点_月时profile.csv` 仅用于模型校核 |
| 模型 | 测算程序 |
| 优化缓存 | 十年联合定容各算例结果、推荐配置十年逐时调度 |
| 报告 | 定容测算报告、十年逐时调度底稿、报告插图 |

## 运行环境

Windows，Python 3.11，Microsoft Office（生成报告公式时调用 Office 自带的 MML2OMML.XSL）。

```
pip install -r 模型/requirements.txt
```

## 运行

```
cd 模型
python run_all.py              # 已有优化缓存的算例直接读取，约{T_CACHE}分钟
python run_all.py --rerun      # 全部重新计算，约{T_RERUN}小时
python run_all.py --only doc   # 只运行其中一步
```

| 步骤 | 程序 | 内容 |
|---|---|---|
| clean | mk_wp_ninja.py、mk_price.py | 由原始数据生成处理后输入 |
| check | lp_multi.py check | 单年算例与《绿电直连定容测算》框架计算结果对比 |
| opt | bd10y.py | 十年逐时联合定容，按年 Benders 分解求解 |
| dispatch | dispatch_10y.py | 推荐配置十年逐时调度 |
| doc | fig_schematic.py、fig_typical.py、mk_dispatch_xlsx.py、mk_report_docx.py | 报告插图、调度底稿、定容测算报告 |

模型公式与参数见 `lp_multi.py`。重新下载光伏出力需先设置环境变量 `NINJA_TOKEN`。

## 优化缓存

| 文件名前缀 | 算例 |
|---|---|
| `_bd10y_trk_` | 基准 |
| `_bd10y_trk_nobatt_` | 不配置储能 |
| `_bd10y_trk_bx1.1_`、`_bd10y_trk_bx1.2_`、`_bd10y_trk_bx1.3_` | 储能造价上浮10%、20%、30% |
| `_bd10y_trk_cgfix_` | 申报需量不可削减 |

前缀后接 `容量.npy`（容量及年均成本）、`迭代.csv`（迭代过程）、`逐年.csv`（逐年运行统计）、`割平面.npy`（割平面）。
`_dispatch_10y_trk_推荐.npz` 为推荐配置十年逐时调度，`典型工况统计.json` 为报告典型工况数据。
